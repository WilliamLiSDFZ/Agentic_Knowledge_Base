# Why Don’t Prompt-Based Fairness Metrics Correlate?

**Source**: https://aclanthology.org/2024.acl-long.487/

## [POSITIVE] CAIRO (Correlated Fairness Output)
A method that augments original fairness metric prompts using multiple pretrained language models, then selects prompt combinations that achieve the highest Pearson correlation across metrics.

**Delta**: Pearson correlation improved from 0.3 to 0.90 (gender) and from 0.18 to 0.98 (religion)
**Condition**: When fairness metrics target overlapping or similar demographic subgroups

**Evidence**: "We show a significant improvement in Pearson correlation from 0.3 and 0.18 to 0.90 and 0.98 across metrics for gender and religion biases, respectively."

## [POSITIVE] Prompt Data Augmentation via Paraphrasing
Using multiple large-scale language models (ChatGPT, LLaMA 2, Mistral) to generate quasi-paraphrases of original fairness metric prompts, introducing lexical variations while preserving semantics.

**Delta**: Enables correlation improvement from ~0.3/0.18 to 0.90/0.98
**Condition**: Applied to prompt-based fairness metrics (BOLD, HolisticBias, HONEST)

**Evidence**: "CAIRO leverages the freedom of selecting particular prompt combinations (obtained through data augmentation) inherent to prompt-based fairness metrics. Such augmentation is performed by prompting several pre-trained language models to introduce lexical variations in the original prompts, preserving the semantics of the original prompts."

## [POSITIVE] Multi-Model Prompt Generation
Using multiple distinct language models (ChatGPT, LLaMA 2, Mistral) to generate paraphrases from different distributions, rather than a single model.

**Delta**: All models contribute to best prompt combinations when number of prompts > 2
**Condition**: When paraphrasing models have sufficiently distinct training data distributions

**Evidence**: "All models contribute to finding the best prompt combination in terms of correlation. In other words, the prompts that compose the best correlation across metrics are consistently generated by all the models, especially as the number of prompts in the combination grows."

## [POSITIVE] Prompt Selection (Best Combination Search)
Selecting the specific prompt combinations from augmented prompts that maximize Pearson correlation across fairness metrics, rather than using all combinations or averaging.

**Delta**: Outperforms average-combination baseline; average baseline does not improve with more prompts
**Condition**: Requires sufficient pool of augmented prompts to search over

**Evidence**: "However, this is not the case for the average baseline, which suggests that simply using all available prompt combinations is not a viable alternative. This showcases the importance of selecting specific prompt combinations to uncover matching patterns across different metrics."

## [POSITIVE] Standardizing Bias Quantification Across Metrics
Unifying the bias proxy (toxicity) used across different fairness metrics instead of using each metric's original quantification method (e.g., hurtfulness for HONEST, toxicity for BOLD).

**Delta**: Results in higher correlation as shown in Figure 6
**Condition**: Applied when comparing metrics that originally use different bias proxies

**Evidence**: "We tackled the inconsistency in bias quantification by standardizing the bias proxy across different metrics... Unifying the subgroups targeted by fairness metrics leads to higher correlation."

## [POSITIVE] Unifying Targeted Subgroups Across Metrics
Aligning the demographic subgroups targeted by each fairness metric so that metrics assess the same populations.

**Delta**: Higher correlation observed when subgroups are unified (shown in Figure 6)
**Condition**: When metrics have overlapping subgroup coverage; fails when subgroup overlap is minimal

**Evidence**: "As discussed in Section 4.2, unifying the subgroups targeted by fairness metrics leads to higher correlation."

## [NEGATIVE] Varying Prompt Sentence Structure
Altering the grammatical structure of prompts (e.g., active vs. passive voice) which causes significant changes in model bias measurements.

**Delta**: Metric scores for religion bias change substantially across 10 models
**Condition**: Uncontrolled variation in prompt structure across fairness metrics

**Evidence**: "Prompt sentence structure refers to the impact of altering the grammatical structure in a prompt. For example, it has been shown that using active or passive voice in a prompt can lead to distinct model responses."

## [NEGATIVE] Varying Prompt Verbalization
Changing the wording of prompts while maintaining sentence structure, which leads to different model responses and bias measurements.

**Delta**: BOLD metric scores for religion bias change substantially over 10 models across paraphrases
**Condition**: When different fairness metrics use different verbalizations for similar concepts

**Evidence**: "Prompt verbalization involves changing the wording of prompts while maintaining the sentence structure. For instance, a model may generate different responses for prompts like 'the capital of the U.S. is [BLANK]' and 'the capital of America is [BLANK]'."

## [NEGATIVE] Varying Prompt Distribution (Source Model)
Using prompts generated by different language models (ChatGPT, LLaMA 2, Mistral) which have different training data distributions, affecting bias measurement values.

**Delta**: Religion bias measured by BOLD changes based on which model generated the paraphrases
**Condition**: When prompt source distribution is not controlled across metrics

**Evidence**: "The source distribution of a prompt can affect model responses by influencing overlap with the model's pre-training data... We observe that religion bias, measured by BOLD over 10 language models, changes based on the model used for prompt augmentation."

## [NEGATIVE] Heterogeneous Bias Quantification Methods
Different metrics using different proxies for bias (e.g., toxicity vs. hurtfulness) or different classifiers, leading to divergent bias assessments.

**Delta**: HONEST gender bias values change substantially when switching from hurtfulness to toxicity quantification
**Condition**: When comparing metrics that use different bias quantification approaches

**Evidence**: "Figure 4 shows that the bias values from HONEST on gender bias vary by changing the bias quantification measurement from hurtfulness – as proposed in the original paper – to toxicity."

## [NEGATIVE] Differing Prompt Lexical Semantics Across Metrics
Metrics using prompts with inherently different lexical content (e.g., HONEST prompts designed to trigger hurtful responses vs. neutral BOLD prompts), causing disparity in bias measurement.

**Delta**: Results in disparity in how different metrics measure bias of the same model
**Condition**: When comparing metrics with substantially different prompt lexical content

**Evidence**: "Even with standardized bias quantification methods and classifiers, prompts' lexical semantics can vary, affecting model responses. For example, HONEST prompts may be designed to trigger hurtful responses, while BOLD prompts may not include such language."

## [NEGATIVE] Mismatched Targeted Subgroups Across Metrics
Different metrics targeting different demographic subgroups (e.g., BOLD targets American actors/actresses for gender while HolisticBias targets binary/cisgender/non-binary/queer/transgender), reducing expected correlation.

**Delta**: CAIRO fails to achieve high correlation for gender and race bias between HolisticBias and BOLD due to subgroup mismatch
**Condition**: When fairness metrics target substantially different or non-overlapping demographic subgroups

**Evidence**: "CAIRO fails to result in high correlation due to the absence of common subgroups targeted by the fairness metrics. More specifically, the subgroups targeted by BOLD for gender bias are: American actors and actresses; while the sub-groups targeted by HolisticBias are: binary, cisgender, non-binary, queer, and transgender."

## [POSITIVE] Increasing Number of Prompt Combinations
Using larger combinations of augmented prompts in CAIRO's selection process, allowing more diverse search space for correlated prompt sets.

**Delta**: Improvement in correlation grows with the size of the combinations
**Condition**: Applied within CAIRO framework; does not apply to naive averaging baseline

**Evidence**: "We observe that CAIRO significantly improves the metrics correlation compared to using the original prompts (i.e. the number of prompts equals 1). The improvement grows with the size of the combinations, which is to be expected."

## [NEUTRAL] BERT-based Toxicity Evaluation
Using BERT to evaluate toxicity of model continuations as a standardized bias proxy across all metrics.

**Delta**: Enables standardization but classifiers may have inherent biases
**Condition**: Used as unified bias quantification across BOLD, HolisticBias, and HONEST

**Evidence**: "Content is deemed toxic if it leads individuals to disengage from a discussion, and we use BERT for toxicity evaluation, similar to Dhamala et al. (2021)."

## [NEUTRAL] Sampling-based Text Generation (vs. Greedy Decoding)
Using sampling instead of greedy decoding for generating model continuations during fairness evaluation.

**Delta**: Not quantified separately
**Condition**: Applied during text generation for all evaluated models

**Evidence**: "We employed sampling, instead of using greedy decoding. No beam search was utilized."
